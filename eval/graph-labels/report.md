标注集里 `noise` 共 **9** 条；被计成误报 **1** 条。结论：

1. **格式示例会真的建出边，而不是理论风险。** ADR-0027 里那句「「参见《X》第 2.4 节」「本文件第三节」、Markdown 链接、同文档锚点」是表格的「例子」格，抽取器照样把它当成作者的引用；这次它建出的边恰好与另一条真标注重合（撞对），**没被计成误报**。撞对是巧合：同一个节里没有「第 3 节」时它就会长成一条假引用。
2. **否定语境（已作废 / 已关闭 / 不再追踪）会命中正则**：会议纪要里「《产品周会纪要（2026-11-03）》第 4 节的待办已全部关闭」被建成一条边。这是本档唯一被计成误报的 noise 条。
3. **「已废止的旧文档」这一类反而不会长成误报**：`原《优惠券使用细则》第 2 条已废止` 的目标文档不在库里，抽取器解析不到目标，一条边都不建。所以**否定词清单要挡的是上面那两种（格式示例、语境否定），不是「文档已废止」**——后者由「目标必须存在」这条规则天然挡住。

## 八、顺带发现（与本票的结论无关，但不该被埋掉）

- `docs/adr/0015-token-window-and-vocab.md` 的正文里含 `<|endoftext|>` 这个 tiktoken 特殊 token 的**字面量**，生产切块器（`app/utils/tokenizer.py`）对它直接抛 `ValueError: disallowed special token`。也就是说：上传一篇正文里出现这个字面量的文档，索引会失败。这一篇因此被排除在本测量的目录之外（`labels.json` 的 `exclude`），另记一笔。
- 测量集里有两类「解析侧」的漏法值得分开看：①`本文件第 1 节` 这种**写法完全在规则内**的引用，在标题写成「第 N 节 X」的政策文档上解析失败——`section_by_number` 认的是「标题以数字开头」，而中文法规的编号惯例是「第 N 条 / 第 N 节 X」，这条口径对政策类文档是系统性失效，不是个案；②整篇链接（`[ADR-0025](0025-….md) 决策五`）会解析到目标文档的 **h1 那一节**——ADR 的 h1 节里只有「状态 / 日期 / 相关」三行元信息，于是边建出来了、方向也对、粒度却错。
